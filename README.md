# 📊 E-commerce Analytics Dashboard

Интерактивный дашборд для анализа продаж интернет-магазина, построенный с использованием **Python** и **Streamlit**. Проект визуализирует ключевые бизнес-метрики, динамику заказов по дням недели и распределение выручки по категориям товаров.

---

## 🛠 Технологический стек
- **Python 3.10+**
- **Streamlit** (веб-интерфейс)
- **Pandas** (обработка и очистка данных)
- **Matplotlib** (построение визуализаций)

---
